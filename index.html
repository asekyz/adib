ADIB Employee Digital Workplace Knowledge Base

This knowledge base contains employee guidance for Microsoft 365 mobile enrollment, multi-factor authentication, Microsoft Authenticator, passwordless sign-in, Cisco AnyConnect VPN, and vOffice remote access.

Mobile Device Enrollment

First-Time Mobile Setup

  1. Enroll the mobile device.
  2. Install Microsoft Authenticator.
  3. Configure Microsoft Authenticator.
  4. Add a backup authentication method.

Replacing an Existing Device

  1. Open Security Info Portal.
  2. Delete the old registered device.
  3. Remove device management profile from the old device.
  4. Enroll the new device.
  5. Configure authentication methods.

Remove Existing Mobile Device

Access Security Info Portal:

https://aka.ms/mysecurityinfo

iPhone / iPad

Settings → General → VPN & Device Management → Management Profile → Remove Management

Android

Settings → Users & Accounts → Work Account → Remove Work Profile → Delete

iOS Enrollment

Enroll an iPhone or iPad into Microsoft 365 using Safari.

  1. Open Safari.
  2. Go to https://aka.ms/iosenrollment
  3. Sign in using ADIB credentials.
  4. Select Get Started.
  5. Select Continue.
  6. Allow Management Profile download.
  7. Open Settings.
  8. Select VPN & Device Management.
  9. Select Management Profile.
  10. Select Install.
  11. Select Trust.
  12. Wait for applications to install.

Android Enrollment

  1. Install Microsoft Intune Company Portal from Google Play.
  2. Sign in using ADIB credentials.
  3. Allow all required permissions.
  4. Select Begin Enrollment.
  5. Complete enrollment.
  6. Open Company Portal.
  7. Wait for applications to install.

Microsoft Authenticator Enrollment

Microsoft Authenticator is the primary authentication method required for access to ADIB services.

  1. Install Microsoft Authenticator.
  2. Open Security Info portal.
  3. Select Add Method.
  4. Select Authenticator App.
  5. Select Add.
  6. Select Next.
  7. Scan QR Code.
  8. Approve Number Matching challenge.
  9. Select Next.
  10. Complete registration.

Passwordless Authentication

  1. Open Microsoft Authenticator.
  2. Select Abu Dhabi Islamic Bank account.
  3. Select Enable Phone Sign-In.
  4. Select Continue.
  5. Enter Windows password.
  6. Approve sign in request.
  7. Passwordless sign-in becomes active.

Secondary Authentication Method

  1. Open Security Info Portal.
  2. Select Add Method.
  3. Select Phone.
  4. Enter mobile number.
  5. Select Text Me A Code.
  6. Enter SMS verification code.
  7. Select Done.

Cisco AnyConnect VPN

Use Cisco AnyConnect when connecting an ADIB laptop outside the ADIB network.

  1. Open Cisco AnyConnect from the taskbar.
  2. Select personal Wi-Fi network.
  3. Select Connect.
  4. Enter Wi-Fi password.
  5. Select OK.
  6. Wait for connection to complete.

vOffice Access

vOffice provides remote access to business applications and virtual desktop services.

Prerequisites

  • ADIB account.
  • MFA setup completed.
  • Microsoft Authenticator configured.
  • vOffice access approved.

Access from Home

  1. Install Citrix Workspace.
  2. Browse to https://voffice.adib.ae
  3. Sign in using ADIB email.
  4. Enter Windows password.
  5. Approve Microsoft Authenticator request.
  6. Complete Citrix Gateway validation.
  7. Launch vOffice desktop.

Frequently Asked Questions

I changed my mobile phone. What should I do?

Delete the old device from Security Info, remove the profile from the old device, and enroll the new device.

I cannot access Microsoft Authenticator.

Use SMS verification if previously configured.

How do I enable Passwordless Authentication?

Open Microsoft Authenticator, choose the ADIB account, select Enable Phone Sign-In, and complete verification.

How do I work remotely?

Use Cisco AnyConnect VPN or vOffice remote desktop depending on service requirements.

How long does enrollment take?

Application deployment may take up to 15 minutes after successful enrollment.
