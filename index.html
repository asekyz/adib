Virtual Office Access Guide

Virtual Office provides secure access to corporate business applications and virtual desktop resources.

Prerequisites

  • Active corporate user account.
  • Multi-Factor Authentication configured.
  • Microsoft Authenticator installed and activated.
  • Virtual Office access approved through the IT Service Catalog.

Using Virtual Office from the Office Network

  1. Open Citrix Workspace.
  2. Select the Virtual Office desktop.
  3. Launch required business applications.

Using Virtual Office from Home

  1. Install Citrix Workspace.
  2. Browse to the company Virtual Office gateway URL.
  3. Sign in using your corporate email and password.
  4. Approve the MFA notification in Microsoft Authenticator.
  5. Complete Citrix Gateway Endpoint Analysis.
  6. Launch the Virtual Office desktop.

Cisco AnyConnect VPN

Use Cisco AnyConnect when connecting an enterprise laptop from an external network such as home Wi-Fi.

Steps

  1. Open Cisco AnyConnect from the taskbar.
  2. Select personal Wi-Fi network.
  3. Click Connect.
  4. Enter Wi-Fi password.
  5. Click OK.
  6. Wait for successful connection.

Microsoft Authenticator Enrollment

Microsoft Authenticator is required for Multi-Factor Authentication and Passwordless Sign-In.

Enrollment Steps

  1. Download Microsoft Authenticator from App Store or Google Play.
  2. Open Security Info Portal.
  3. Sign in using corporate credentials.
  4. Select Security Info.
  5. Select Add Method.
  6. Select Authenticator App.
  7. Select Add.
  8. Select Next.
  9. Scan QR Code.
  10. Complete Number Matching verification.
  11. Select Next.

Enable Passwordless Sign-In

  1. Open Microsoft Authenticator.
  2. Select the corporate account.
  3. Select Enable Phone Sign-In.
  4. Select Continue.
  5. Enter Windows password.
  6. Approve Sign-In request.

After successful configuration, Microsoft Authenticator can be used for passwordless authentication.

Authentication Methods Setup

Primary Authentication Method

  1. Install Microsoft Authenticator.
  2. Open Security Info portal.
  3. Add Authenticator App.
  4. Scan QR Code.
  5. Complete number matching verification.

Secondary Authentication Method

  1. Open Security Info portal.
  2. Select Add Method.
  3. Select Phone.
  4. Enter mobile number.
  5. Select Text Me A Code.
  6. Enter verification code.
  7. Select Done.

Frequently Asked Questions

I changed my mobile phone. What should I do?

Remove the old device from Security Info, delete the management profile from the old phone, and enroll the new device.

I cannot access Microsoft Authenticator.

Use the alternative SMS authentication method if previously configured.

How do I access corporate resources while working from home?

Use Cisco AnyConnect or access Virtual Office through Citrix Workspace depending on the service required.

How do I enable Passwordless Sign-In?

Open Microsoft Authenticator, select your company account, enable Phone Sign-In, and complete verification.

How long does mobile enrollment take?

Applications may take up to 15 minutes to appear after enrollment completes.
