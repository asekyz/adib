ADIB Mobile Device Enrollment Knowledge Base

This knowledge base provides guidance for enrolling iOS and Android mobile devices into Microsoft 365, configuring Microsoft Authenticator, enabling passwordless sign-in, and setting up secondary authentication methods.

Scenario 1: First Time Mobile Setup

  1. Enroll the mobile device.
  2. Configure Microsoft Authenticator.
  3. Configure a backup authentication method.

Scenario 2: Replacing an Existing Device

  1. Open Security Info.
  2. Delete the old registered authentication device.
  3. Remove the management profile or work profile from the old device.
  4. Enroll the new device.
  5. Configure Microsoft Authenticator.
  6. Configure a secondary authentication method.

Security Information Portal

Access Security Info Portal:

https://aka.ms/mysecurityinfo

Use this portal to:

  • Remove old mobile devices.
  • Add Microsoft Authenticator.
  • Add SMS verification.
  • Enable passwordless authentication.
  • Manage authentication methods.

Remove Existing Mobile Device

Common Steps

  1. Open Security Info Portal.
  2. Sign in using ADIB credentials.
  3. Select Security Info.
  4. Delete the old device.

iOS

Settings → General → VPN & Device Management → Management Profile → Remove Management

Android

Settings → Users & Accounts → Work Account → Remove Work Profile → Delete

iOS Enrollment

Enrollment URL:

https://aka.ms/iosenrollment

  1. Open Safari.
  2. Browse to the enrollment URL.
  3. Sign in with ADIB credentials.
  4. Select Get Started.
  5. Select Continue.
  6. Allow download of Management Profile.
  7. Open Settings.
  8. Navigate to VPN & Device Management.
  9. Install Management Profile.
  10. Select Trust.
  11. Wait for applications to install.

Android Enrollment

  1. Download Microsoft Intune Company Portal from Google Play.
  2. Sign in using ADIB credentials.
  3. Grant required permissions.
  4. Select Begin.
  5. Complete enrollment.
  6. Open Company Portal.
  7. Wait for applications to install.

Microsoft Authenticator Setup

  1. Open Security Info Portal.
  2. Select Add Method.
  3. Select Authenticator App.
  4. Select Add.
  5. Select Next.
  6. Open Microsoft Authenticator on mobile device.
  7. Scan QR Code.
  8. Approve the number matching challenge.
  9. Complete setup.

Passwordless Sign-In

  1. Open Microsoft Authenticator.
  2. Select ADIB account.
  3. Select Enable Phone Sign-In.
  4. Verify identity.
  5. Complete registration.

Secondary Authentication Method

  1. Open Security Info Portal.
  2. Select Add Method.
  3. Select Phone.
  4. Enter mobile number.
  5. Select Text Me a Code.
  6. Enter SMS verification code.
  7. Select Done.

Troubleshooting

I no longer have access to my old phone

Use "I can't use my Microsoft Authenticator app right now" and authenticate using SMS or voice call.

QR Code is not scanning

Ensure camera permissions are enabled for Microsoft Authenticator.

Apps are not appearing after enrollment

Wait up to 15 minutes after successful enrollment and refresh Company Portal or Management Profile installation.
